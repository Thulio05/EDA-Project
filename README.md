# EDA-Project

Este repositório contém resoluções de exercícios práticos de **Estruturas de Dados e Algoritmos** (EDA), escritos em **C**.  
O objetivo é reforçar conceitos de lógica, algoritmos e uso eficiente de estruturas como arrays, listas, e manipulação de memória.

---

## Sobre o Projeto

Aqui você encontrará soluções para questões típicas de cursos de EDA, com implementação em C de algoritmos básicos.  
Cada exercício ajuda a fixar: lógica de programação, eficiência, tratamento de dados, e prática de escrita de código limpo.

---

## Tecnologias Utilizadas

- Linguagem: **C**  
- Ambiente: compilador GCC ou similar  
- Estruturas abordadas: arrays, ponteiros, laços, funções, controle de fluxo
